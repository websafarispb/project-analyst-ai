# Project Analyst AI Guidelines

## General
- Keep code simple and readable
- Prefer small functions with clear responsibility

## Error Handling
- Always handle possible errors explicitly
- Avoid silent failures

## API Design
- Return structured JSON responses
- Use clear field names

## Agent Design
- Keep tools focused and single-purpose
- Use clear and descriptive tool names and descriptions

## Logging (future)
- Add logging for tool execution and errors
